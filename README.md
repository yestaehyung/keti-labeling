# KETIlabel

## 프로젝트 개요
KETIlabel은 이미지 기반 AI 학습을 지원하기 위한 웹 애노테이션 도구입니다. 드래그 앤 드롭 업로드, 라벨링 워크스페이스, 내보내기 및 학습 파이프라인 연동을 하나의 Next.js 애플리케이션에서 제공합니다. 브라우저 로컬 스토리지를 활용한 임시 저장과 API 연동을 통한 원격 동기화 기능을 함께 사용해 빠른 주석 작업을 지원합니다.

## 주요 기능
- **이미지 업로드 & 갤러리**: 다중 이미지 업로드, 업로드 이후 즉시 갤러리에서 미리보기 및 선택 가능.
- **라벨링 워크스페이스**: 선택한 이미지를 기반으로 폴리곤, 박스 등 주석을 생성하고, 다크 모드 토글과 클래스 관리 기능 제공.
- **모델 학습 관리**: `/training` 경로에서 학습 세션 상태, 로그, 모델 설정을 모니터링하고 갱신.
- **에셋 내보내기**: 주석 결과를 다양한 포맷으로 다운로드하여 외부 학습 파이프라인에 전달.
- **상태 모니터링**: API 상태 위젯과 토스트 알림으로 업로드/학습 진행 상황을 즉시 피드백.

## 디렉터리 구조
```
app/                # Next.js 라우트, 페이지 및 서버 컴포넌트
  models/           # 타입 정의 및 데이터 헬퍼
  training/         # 학습 페이지 및 관련 UI
components/         # 재사용 가능한 UI 컴포넌트와 모듈
hooks/              # React 커스텀 훅
lib/                # API 설정, 유틸리티, 검증 로직
public/             # 정적 에셋 (이미지, 아이콘 등)
styles/             # Tailwind 및 전역 스타일 정의
```

## 시작하기
1. Node.js 18 이상과 `pnpm`이 설치되어 있는지 확인합니다.
2. 저장소를 클론하고 의존성을 설치합니다.
   ```bash
   pnpm install
   ```
3. 개발 서버를 실행하고 브라우저에서 `http://localhost:3000`을 엽니다.
   ```bash
   pnpm dev
   ```

## 필수 명령어
- `pnpm build`: 프로덕션 번들을 생성하여 배포 전에 검증합니다.
- `pnpm start`: 빌드된 결과물을 로컬에서 서비스해 스모크 테스트를 수행합니다.
- `pnpm lint`: Next.js + Tailwind ESLint 규칙을 적용해 코드 스타일을 검증합니다.
- `pnpm exec jest --watch`: Jest 환경이 구성된 후 테스트를 감시 모드로 실행합니다.
- `pnpm exec jest --coverage`: 새 모듈의 커버리지가 80% 이상인지 확인합니다.

## 환경 변수
- 로컬 비밀값은 `.env.local`에 보관하고, 샘플 값은 `.env.example`로 공유합니다.
- API 엔드포인트 및 워크박스 캐싱 정책은 `next.config.mjs`와 `lib/api-config.ts`에서 정의하므로 변경 시 두 파일을 함께 업데이트합니다.
- 서비스 워커 캐싱을 수정한 경우, 배포 노트에 수동 캐시 무효화 절차를 기록합니다.

## 품질 보증 및 기여 가이드
- 코드 변경 전 `pnpm lint`, `pnpm build`를 성공시키고 주석 또는 UI 변경 사항은 스크린샷/영상으로 문서화합니다.
- 테스트 파일은 `*.test.tsx` 형태로 컴포넌트 인접 위치에 두고, 접근성 매처(`toBeInTheDocument`, `toHaveAccessibleName`)를 적극 활용합니다.
- 커밋 메시지는 명령형 현재형으로 간결하게 작성하며, PR에는 변경 요약, 테스트 결과, 연관 이슈를 포함합니다.
- 새 의존성 추가, 환경 변수 도입, 마이그레이션 발생 시 PR 본문과 `AGENTS.md`에 반영해 팀 간 동기화를 유지합니다.
